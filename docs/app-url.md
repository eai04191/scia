# アプリのURL

`scia://`のURLで画面を開くときに、作者が決めたこと。開ける画面のリストはAGENTS.mdの「シミュレーター」にある。アプリの中から画面を開くとき（謝辞の「アカウント」、設定の「アプリ内のSafariの高さ」など）も、同じ入り口を通す。

## 重ねた画面との関係

- タブを選ぶか、タブに積んで見せる行き先（タブ、プロフィール、スレッド、人のリスト、ハッシュタグ、検索、予約投稿、保留中の通知など）は、上に重ねた画面をすべて閉じてから開く。重ねたままでは見えないため。送られた行き先は使う人の新しい操作なので、書きかけのある画面（メモ、プロフィールの編集、通報など）やアプリ内のSafariも閉じ、書きかけや読んでいたページは失う
- 確認のアラートが出ていれば、何も閉じずに開くのをやめる。アラートは答えを待っている途中で、選ばずに閉じると、選んだときの後始末がされないため
- 並びにないか無効にしているタブへの行き先は、開けないので、何も閉じずにやめる。閉じても見せるものがなく、書きかけやページを失うだけになるため
- 設定、メモ、通報、お知らせのように手前に重ねる行き先は、下の画面を残して重ねる。ビューアのメニューの「カスタマイズ」から開いた設定を閉じると、ビューアに戻るため
- 重ねた画面のどれかを閉じている途中に届いたら、閉じ終えてから開く
