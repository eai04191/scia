# Roadmap

各項目は、agentに1タスクとして渡せる単位にしている。上から順に進める前提で、先の項目は前の項目の成果に依存する。

## M0: 検証の土台

- [x] スクロール位置保持のテストハーネス: 任意の件数を上に挿入したとき、基準セルの画面上の位置が変わらないことを検証するUIテストまたはユニットテストの仕組み
- [x] デバッグ用チューニングパネル: デバッグビルドでのみ表示され、値を実行中に変えられる設定画面の仕組み（項目はこの時点では空でよい）
- [x] 違和感レポート: シェイクで直前の状態ダンプ、ログ、メモを保存する仕組み

## M1: ログインとホームタイムライン

- [x] OAuthログイン（`ASWebAuthenticationSession`）とトークンのKeychain保存
- [ ] ホームタイムラインの取得と表示（RESTのみ、下方向への追加読み込み）
- [ ] 投稿本文のHTMLをリッチテキストに変換（リンク、メンション、ハッシュタグ、カスタム絵文字）

## M2: ストリーミング

- [ ] `/api/v1/streaming`のWebSocketクライアントと、イベントのデコード
- [ ] 新着の挿入ポリシー: まとめて挿入する間隔、最上部にいるときの自動追従、それ以外は新着件数の表示
- [ ] 切断と復帰: 再接続と、切れていた間の投稿をRESTで埋めるギャップ処理（重複と漏れのテストつき）
- [ ] markers APIによる既読位置の同期

## M3: 毎日使えるまで

- [ ] 通知タブ
- [ ] 投稿、返信、ふぁぼ、ブースト
- [ ] 画像の表示とビューア
- [ ] リスト、ローカル、連合タイムライン
