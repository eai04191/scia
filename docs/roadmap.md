# Roadmap

各項目は、agentに1タスクとして渡せる単位にしている。上から順に進める前提で、先の項目は前の項目の成果に依存する。

## M0: 検証の土台

- [x] スクロール位置保持のテストハーネス: 任意の件数を上に挿入したとき、基準セルの画面上の位置が変わらないことを検証するUIテストまたはユニットテストの仕組み
- [x] デバッグ用チューニングパネル: デバッグビルドでのみ表示され、値を実行中に変えられる設定画面の仕組み（項目はこの時点では空でよい）
- [x] 違和感レポート: シェイクで直前の状態ダンプ、ログ、メモを保存する仕組み

## M1: ログインとホームタイムライン

- [x] OAuthログイン（`ASWebAuthenticationSession`）とトークンのKeychain保存
- [x] ホームタイムラインの取得と表示（RESTのみ、下方向への追加読み込み）
- [x] 投稿本文のHTMLをリッチテキストに変換（リンク、メンション、ハッシュタグ、カスタム絵文字）

## M2: ストリーミング

- [x] `/api/v1/streaming`のWebSocketクライアントと、イベントのデコード
- [x] 新着の挿入ポリシー: まとめて挿入する間隔、最上部にいるときの自動追従、それ以外は新着件数の表示
- [x] 切断と復帰: 再接続と、切れていた間の投稿をRESTで埋めるギャップ処理（重複と漏れのテストつき）
- [x] markers APIによる既読位置の同期

## M3: 毎日使えるまで

- [x] 通知タブ
- [x] 投稿、返信、ふぁぼ、ブースト
- [x] 画像の表示とビューア
- [ ] ~~リスト、ローカル、連合タイムライン~~（普段使わないのでいらない）
- [x] 複数アカウントの切り替え（一度に使うのは1アカウント）

## M4: Monaから乗り換えられるまで

Monaを開かずに1日過ごせることを完了の条件にする。項目どうしの優先度は同じくらいで、並び順は着手の順番を表さない。

- [ ] スレッド（会話）の表示
- [x] プロフィール画面（投稿の一覧、フォローの状態）
- [ ] 投稿へのメディアの添付と、代替テキストの入力
- [ ] 自分の投稿の編集と削除
- [ ] ブックマーク
- [ ] 注意書き（CW）付きの投稿の折りたたみと展開
- [ ] 投票の表示と投票

## M5: 毎日使って見つけた改善

M4までで足りない機能や違和感を、使いながら1つずつ足す。設計に関わる大きな機能は予定せず、これまでに足した、説明にならない代替テキストを隠す設定や、一覧のサムネイルを元の画質で表示する設定のような、設定や表示の細かい改善が中心になる。項目は見つけた時点でここに追加する。

- [ ] トランジションとAPIリクエストの点検: 画面遷移ごとにアニメーションの途中の操作で破綻しないか、タイムラインの更新で不要なリクエストを送っていないかを確かめる
- [ ] プロフィールのアイコンとヘッダー画像をタップして、ビューアで大きく見る: ビューアは開閉の起点にサムネイルのビュー（MediaTileView）を使うため、アイコンとヘッダー画像からも起点を渡せるようにする
- [ ] 本文のメンションをタップして、プロフィールを開く: 本文のリンクがまだタップできないため、リンクのタップと一緒に入れる。開く相手のIDは`status.mentions`から引ける
- [ ] フォローしたあとに、フォロワー数を読み直す: フォローのAPIは関係だけを返すため、いまはプロフィールを開き直すまで数が古いまま
- [x] タブバーの上に常に置く投稿欄: 1、2行の短い投稿や返信を、タイムラインを見たまま書けるようにする。書いていないときは細いカプセルにして閲覧を邪魔せず、書くときは同じバーがキーボードの上へ上がる
- [ ] 投稿欄の下書きを、アプリを起動し直しても残す: いまはメモリにだけ持っている
- [ ] 投稿欄で注意書き（CW）を書く: いまは全画面の投稿画面に広げたときだけ書ける
