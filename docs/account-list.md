# 人の一覧

投稿をお気に入りした人とブーストした人、フォローとフォロワーの一覧で、作者が決めたこと。

- 4つの一覧は、1つの画面を使い回す。読むAPIだけを変える（`GET /api/v1/statuses/:id/favourited_by`、`reblogged_by`、`GET /api/v1/accounts/:id/followers`、`following`）
- 画面はシートではなく、プロフィールやスレッドと同じくpushで開く。一覧から人を押すとプロフィールへ進み、その先にも進む、見て回る画面のため。シートは、編集や通報、代替テキストのような、作業や補足に使う。どこから開いても、端からのスワイプで同じように戻れる
- 並びはサーバーが返すとおりにし、続きは応答の`Link`ヘッダーの`next`から読む
- 行を押すと、その人のプロフィールを開き、長押しすると、その人のユーザーのメニューを出す
- 名前が入りきらないときは、投稿のセルの名前と同じく行末をぼかす

## 入口

- 通知のまとまりの「ほかn人」。決まりは[notification-display.md](notification-display.md)の「まとめて表示する」
- 投稿のメニューの「お気に入りした人」「ブーストした人」。決まりは[menus.md](menus.md)にある
- プロフィールのフォローとフォロワーの数。数と名前のどちらを押しても開く。投稿の数は押せない。プロフィールの下の一覧で投稿を見られるため
