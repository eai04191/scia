# 長い投稿

本文の長い投稿をタイムラインでどう切り、どう広げるかで、作者が決めたこと。

## 切る

- 本文が「切り始める行数」を超えたら、「切ったときの行数」まで出して切る。少しだけ長い投稿を切ると、広げる手間のわりに隠れる行が少ないため、切り始める行数と切ったときの行数を分ける
- 行数は、タイムラインに並べたときの幅で折り返した行で数える。端末の幅や文字の大きさで変わる
- 数えるのは本文だけにする。添付ファイル、投票、リンクカードは高さが決まっているので、切らずにそのまま本文の下に出す
- 引用とXの投稿の囲みの本文も、同じ値で切る。外側の本文と囲みの本文は別々に数え、片方を広げてももう片方は切ったままにする
- 2つの行数は「投稿の見た目」の本文の項目で選ぶ。既定は、公式のWebクライアントに合わせて、32行を超えたら15行に切る。切り始める行数を0にすると切らない。切ったときの行数が切り始める行数より多ければ、切り始める行数まで出す

## 切らない本文

- スレッドの画面で開いている投稿。タイムラインで投稿を押してスレッドを開くのは、全文を読むためでもあるため
- 注意書き（CW）のある投稿。注意書きを開いたあとにも「続きを読む」を押させると、手間が重なるため
- 通知で再掲する投稿は、通知の見た目の行数で切るので、ここでは切らない

## 続きを読む

- 切った本文の最後の行の末尾に「続きを読む」を出す。最後の行の文字は、ボタンの手前で薄くしてボタンにつなぐ
- 押すと、その場で全文に広げる。スレッドを開いたりはしない。画面を移らずに読み続けられ、アプリの中に開く画面がないXの投稿の囲みとも同じ動きにできるため
- 広げるときは、[vision.md](vision.md)の「タイムラインの動き」の、見えている行の高さが変わるときと同じく、下の行ごと動かしてつなぐ。上端が表示領域より上にある行も、その行の位置は保ったまま下の行を動かす
- 広げたことは、投稿ごとにアプリを起動している間だけ覚え、同じ投稿のブーストや通知の行、引用の囲みにもそろえる。どの画面で広げても、開いているほかの画面と、あとで開く画面にもそろえる。Xの投稿は、Xの投稿ごとに覚える
- 同じ投稿の行が押した行より上にも並んでいると、その行も伸びる。そのときも、押した行の画面上の位置を保つ
- 広げた本文を切り直すボタンは出さない。公式のWebクライアントと同じ
- 切っている本文では、「テキストを選択」を出さない（[menus.md](menus.md)）
