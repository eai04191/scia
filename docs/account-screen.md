# 設定とアカウントの画面

設定やアカウントに属する画面を、どこに置き、どこから開くかについて、作者が決めたこと。

## 置き場所

- 入口は「設定」と「アカウントの画面」の2つに分ける。設定には、この端末に保存するものを置く。アカウントの画面には、サーバーにあるものを置く
- 設定は、プリセットに含めるものをアカウントごとに変えるときは、アカウントにプリセットを割り当てる（[preset.md](preset.md)）。項目を1つずつアカウントごとに持つのは、タブの並びのように、アカウントをまたいで共有できないものだけ
- 設定のトップは、先頭にログイン中のアカウントの節を置き、ハンドルを見出しにする。この節には、アカウントの画面を開く「アカウント」と「タブ」を並べる。あとの節は、すべてのアカウントに効く設定を並べる
- 設定のトップの、ログイン中のアカウントの節のすぐ下に、「アカウントを管理」の行だけの節を置く。ログインしているアカウントをまとめて扱う画面を開く

## アカウントの画面

- アカウントのメニューの「アカウント」と、設定のトップの「アカウント」の両方から開く。メニューからはシートで開き、設定からは設定の画面に重ねる
- 節は、誰のものかで分ける。画面の上は指から遠いので、よく開くものを先頭に置かない
  - 先頭の、サーバーのドメインを見出しにした節に、サーバーが全員に出すものを並べる: サーバーのお知らせ
  - 次の、ハンドルを見出しにした節に、このアカウントが持つものを並べる: プロフィール、ブックマーク、お気に入り、フォロー中のハッシュタグ、予約投稿、リスト
  - その次の節に、このアカウントのサーバーでの設定を並べる: 外観（「外観」）、投稿のデフォルト、フィルター（[filters.md](filters.md)の「作る、変える、消す」）、ミュートしたユーザー、ブロックしたユーザー、ブロックしたドメイン（[moderation-lists.md](moderation-lists.md)）、通知のフィルタリング。ミュートとブロックの3つのほかは、Mastodonのウェブの設定と同じ順にするプロフィールの編集は置かず、プロフィールの「プロフィールを編集」から開く（[profile.md](profile.md)）
  - いちばん下にログアウト
- サーバーの機能がないと分かった項目（通知のフィルタリング）は出さない
- ハンドルを見出しにした節の項目を押したら、アカウントの画面（設定から開いていれば設定ごと）を閉じ、その画面をタブの画面に開く。開いた画面のリンクや投稿への操作は、タブの画面の上で行うため。閉じ始めるのと同時にアニメーションなしで開き、閉じていく画面の下に行き先がもう出ているようにする。閉じ終えるのを待ってから開くと、元の画面が一度見えてから行き先へ移るため。ログアウトは、閉じ終えてから始める
- サーバーのお知らせと、サーバーでの設定の節の項目（投稿のデフォルト、外観、フィルター、ミュートしたユーザー、ブロックしたユーザー、ブロックしたドメイン、通知のフィルタリング）は、アカウントの画面を閉じずに、「リスト」と同じくその中で次の画面へ進む。戻るとアカウントの画面に戻る。その画面の中で用が済むため。お知らせの本文のリンクと、ミュートやブロックのリストの人を押したときだけ、アカウントの画面を閉じてから、タブの画面に開く。URL（`scia://filters`、`scia://accounts/muted`など）や、保留中の通知のリストから開いたときは、単独のシートで出す
- タブに置ける項目（ブックマーク、お気に入り、フォロー中のハッシュタグ、予約投稿、リスト）は、タブに並べていればそのタブを開く。タブを無効にしていれば、選んでいるタブに積む。タブに置くかどうかと関係なく、開けるようにするため
- 「リスト」は、自分のリストを並べた画面を重ねる。リストを押すとそのタイムラインを開き、名前、メンバー、返信の表示は、タイムラインの右上のメニューで変える（[lists.md](lists.md)の「変える」）。右上の＋で作り、左へスワイプして消す

## 投稿のデフォルト

新しく投稿するときの既定を、アカウントの画面の「投稿のデフォルト」で変える。値はサーバーにあり、ほかのクライアントと共有される。APIは`PATCH /api/v1/accounts/update_credentials`の`source[...]`。

- 並べるのは、公開範囲、引用できる人、言語、「メディアを閲覧注意にする」の4つ
- 公開範囲は、公開、ひかえめな公開、フォロワーのみから選ぶ。サーバーの既定に、メンションした相手のみはない
- 引用できる人は、引用に対応していないサーバーでは出さない。既定の公開範囲がフォロワーのみの間は、投稿欄と同じく「自分のみ」を見せて選べなくする
- 言語は、投稿欄の言語のシートと同じリストから選ぶ。たくさんの言語の中から探さずに済むよう、端末の言語と、投稿欄で最近選んだ言語を「候補」として先に並べる
- 選んだらすぐ保存する。保存できなければ、元の値に戻して理由を出す
- 保存できたら、開いている投稿欄の既定にもすぐ反映する。自分で選んでいた公開範囲や言語は変えない

## 外観

Sciaが従うのにAPIでは変えられないアカウントの設定（`reading:*`）を、アカウントの画面の「外観」で見せる。`GET /api/v1/preferences`は読むだけで、`update_credentials`は投稿の既定値しか受け付けない。名前は、変える先のMastodonのウェブの画面に合わせる。

- 画面のいちばん上の節の1行目に、これらがMastodonのウェブで設定した外観の好みで、表示設定の値として使えるが、ウェブ以外から変更できないことを書く。見出しやフッターには書かない。その下の行に、Mastodonのウェブの「外観」（`/settings/preferences/appearance`）をSafariで開くボタンを置く
- その下の節に、アニメーションGIFを自動再生する、メディアの表示、閲覧注意としてマークされた投稿を常に展開するの3つを、名前と値の行で見せる。項目の名前と並びはMastodonのウェブに合わせる
- 画面を開いたときと、アプリに戻ってきたときに読み直す。読めなければ、前に読めた値を出したままにし、読めた値がなければ読み込めなかったことを出す

## アカウントを管理

ログインしているアカウントを並べ、並べ替え、切り替え、ログアウト、ログインし直し、追加を行う画面。アカウントのメニューは行を絞るため、アカウントの群を扱う操作はここに集める。

- アカウントを、アカウントのメニューと同じ順に並べる。行には、アイコン、名前、ハンドルを出し、今のアカウントにチェックマークを付ける
- 画面を出すたびに、アカウントごとに`GET /api/v1/accounts/verify_credentials`を読み、アイコンと名前にする。読めるまでと読めなかったときは、人の記号と`@username`を出す。読み直している間は、前に読めたものを出したままにする
- 401が返ったアカウントは、ハンドルの下に「ログアウトされています」と出し、行の末尾に「ログインし直す」ボタンを置く。押すと、そのアカウントにログインし直す。今のアカウントは切り替えない。ログインし直せたら読み直す。端末から資格情報は消さない
- 行を押すと、そのアカウントに切り替える。アカウントのメニューから選んだときと同じく、書きかけの投稿があれば、捨ててよいか確かめる。今のアカウントを押しても何もしない
- 行を長押ししてドラッグし、並べ替える。並びはアカウントのメニュー、「別のアカウントで」、投稿欄の「投稿するアカウント」、プリセットの「アカウントごと」、ショートカットのアカウントの候補の順になる
- 行を左へスワイプして出す「ログアウト」で、そのアカウントからログアウトする。今のアカウントでなくても、切り替えずにログアウトできる。確かめるアラートは、アカウントの画面のログアウトと同じものを使い、書きかけの投稿が破棄されることは、今のアカウントのときと、投稿欄でそのアカウントを選んで書きかけのときだけ添える（[compose.md](compose.md)の「アカウントを変えるとき」）
- いちばん下の節に「アカウントを追加」を置く。アカウントのメニューの「アカウントを追加」と同じ流れにする

## アカウントのメニュー

タブの根の画面の左上のボタンから出す。アカウントが増えても狭くならないよう、行を絞る。

- アカウント、操作の状況、アカウントのリスト、アカウントを追加、設定を並べる
- サーバーのお知らせは、未読があるときだけ、未読の件数を添えて並べる。未読がなければ、アカウントの画面から開く
- 自分のプロフィール、通知のフィルタリング、ログアウトは並べず、アカウントの画面に置く
