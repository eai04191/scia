# 設定とアカウントの画面

設定やアカウントに属する画面を、どこに置き、どこから開くかについて、作者が決めたこと。

## 置き場所

- 入口は「設定」と「アカウントの画面」の2つに分ける。設定には、この端末に保存するものを置く。アカウントの画面には、サーバーにあるものを置く
- 設定は、どの項目もアプリ全体の値を持ち、アカウントごとに上書きできる形を前提に組む。上書きの仕組みは、要る項目が出たときに足す。今アカウントごとに持つのは、タブの並びのように、アカウントをまたいで共有できないものだけ
- 設定のトップは、先頭にログイン中のアカウントの節を置き、ハンドルを見出しにする。この節には、アカウントの画面を開く「アカウント」と「タブ」を並べる。あとの節は、すべてのアカウントに効く設定を並べる

## アカウントの画面

- アカウントのメニューの「アカウント」と、設定のトップの「アカウント」の両方から開く。メニューからはシートで開き、設定からは設定の画面に重ねる
- 節は、誰のものかで分ける。画面の上は指から遠いので、よく開くものを先頭に置かない
  - 先頭の、サーバーのドメインを見出しにした節に、サーバーが全員に出すものを並べる: サーバーのお知らせ
  - 次の、ハンドルを見出しにした節に、このアカウントが持つものを並べる: プロフィール、ブックマーク、お気に入り、フォロー中のハッシュタグ、予約投稿、リスト
  - その次の節に、このアカウントのサーバーでの設定を並べる: 投稿のデフォルト、フィルター（[filters.md](filters.md)の「作る、変える、消す」）、通知のフィルタリング。プロフィールの編集は置かず、プロフィールの「プロフィールを編集」から開く（[profile.md](profile.md)）
  - いちばん下にログアウト
- サーバーの機能がないと分かった項目（通知のフィルタリング）は出さない
- 項目を押したら、アカウントの画面（設定から開いていれば設定ごと）を閉じてから、その画面を開く。開いた画面のリンクや投稿への操作は、タブの画面の上で行うため
- タブに置ける項目（ブックマーク、お気に入り、フォロー中のハッシュタグ、予約投稿、リスト）は、タブに並べていればそのタブを開く。タブを無効にしていれば、ブックマーク、お気に入り、フォロー中のハッシュタグ、リストは選んでいるタブに積み、予約投稿は手前に重ねて開く。タブに置くかどうかと関係なく、開けるようにするため
- 「リスト」は、自分のリストを並べた画面を重ねる。リストを押すとそのタイムラインを開き、名前、メンバー、返信の表示は、タイムラインの右上のメニューで変える（[lists.md](lists.md)の「変える」）。右上の＋で作り、左へスワイプして消す

## 投稿のデフォルト

新しく投稿するときの既定を、アカウントの画面の「投稿のデフォルト」で変える。値はサーバーにあり、ほかのクライアントと共有される。APIは`PATCH /api/v1/accounts/update_credentials`の`source[...]`。

- 並べるのは、公開範囲、引用できる人、言語、「メディアを閲覧注意にする」の4つ
- 公開範囲は、公開、ひかえめな公開、フォロワーのみから選ぶ。サーバーの既定に、メンションした相手のみはない
- 引用できる人は、引用に対応していないサーバーでは出さない。既定の公開範囲がフォロワーのみの間は、投稿欄と同じく「自分のみ」を見せて選べなくする
- 言語は、投稿欄の言語のシートと同じリストから選ぶ。たくさんの言語の中から探さずに済むよう、端末の言語と、投稿欄で最近選んだ言語を「候補」として先に並べる
- 選んだらすぐ保存する。保存できなければ、元の値に戻して理由を出す
- 保存できたら、開いている投稿欄の既定にもすぐ反映する。自分で選んでいた公開範囲や言語は変えない
- フィルターや通知のフィルタリングと同じく、アカウントの画面を閉じてからシートで開く

## アカウントのメニュー

タブの根の画面の左上のボタンから出す。アカウントが増えても狭くならないよう、行を絞る。

- アカウント、操作の状況、アカウントのリスト、アカウントを追加、設定を並べる
- サーバーのお知らせは、未読があるときだけ、未読の件数を添えて並べる。未読がなければ、アカウントの画面から開く
- 自分のプロフィール、通知のフィルタリング、ログアウトは並べず、アカウントの画面に置く
