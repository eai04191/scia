# まとめて行う操作

一覧で投稿を順番を付けていくつも選び、まとめてブーストや共有をする機能について、作者が決めたこと。いくつもの投稿をブーストしてから自分の投稿で言及するときや、ChatGPTのようなアプリにまとめて渡すときに使う。

## 選び始める

- 投稿のメニューの「選択」で、その一覧で投稿を選ぶ状態に入る。長押しした投稿を1番目に選んだ状態で始める
- 「選択」は投稿のメニューの項目なので、並びの設定で動かしたり隠したりでき、タップや長押しにも割り当てられる。既定では、持ち出す操作のまとまりの「共有」のすぐ後ろに出す
- 選べるのは、投稿の行と、投稿の付いた通知の行。投稿のない通知、ギャップ、人の一覧の行などは選べない。引用の囲みのメニューから選び始めたときは、囲みの投稿ではなく、行の投稿を1番目にする
- 選ぶのは、選び始めた一覧の中だけにする。ほかの一覧の投稿と混ぜない

## 選んでいる間

- 選べる行の右上に丸を出し、選んだ行には、選んだ順の番号を丸の中に出す。写真のピッカーで順番を付けて選ぶときと同じ見せ方にする。選んだ行は、背景も薄く色を付ける
- 行のどこをタップしても、その行を選ぶか外すかを切り替える。外したら、後ろの番号を詰める。本文のリンク、添付ファイル、アイコンなど、行の中の部品のタップと長押しは、選んでいる間は効かない。行の長押しのメニューも出さない
- ナビゲーションバーの左に「キャンセル」、タイトルに選んだ件数を出す。下には、投稿欄のカプセルとタブバーを隠し、まとめて行う操作のボタンを並べたツールバーを出す。写真の選択と同じ形にする。タブバーの上にはツールバーを重ねられないため。何も選んでいないときは、ボタンを押せない
- 選んでいる間は、ストリーミングの新着を一覧に入れずに溜め、選び終えたらまとめて入れる。新着で行がずれると、押そうとした行を押し損なうため。編集や削除と、再接続の補完は、読んでいる行の位置を保ったまま反映する
- 選んだ投稿が一覧から消えたら（削除、ミュートなど）、選択から外して番号を詰める
- 「キャンセル」を押したとき、操作を決めたとき、ほかの画面へ移ったとき、タブを切り替えたときに、選ぶのをやめる

## 操作

- まとめて行う操作は、ブーストと共有にする。お気に入り、ブックマーク、リンクのコピーは、要るようになったら同じ仕組みで足す
- 同じ投稿を2つの行で選んだとき（固定した投稿と、ふだんの行など）は、先に選んだほうの順番で1度だけ行う
- 操作を決めたら選ぶのをやめ、操作はセッションの中で続ける。画面を移っても止まらない

### ブースト

- ボタンを押すとメニューを出し、「選んだ順にブースト」で始める。ブースト済みの投稿の前のブーストに付いた反応が消えるため、ボタン1つで始めずに確かめる。メニューには、ブーストする件数と、付け直す件数、ブーストできずに飛ばす件数を出す
- 選んだ順に1件ずつブーストし、サーバーの応答を待ってから次へ進む。応答を待たずに送ると、サーバーが受け付ける順が前後するため
- ブースト済みの投稿は、ブーストを取り消してから付け直す。Mastodonは、ブースト済みの投稿をもう一度ブーストしても新しく作らずに前のブーストを返し、選んだ順に並ばないため
  - ブースト済みかは、選んだときではなく、その投稿を送る直前に確かめる。送っている間に、ほかの一覧で後ろの投稿をブーストすることがあるため。確かめられないときはブースト済みとみなす。ブーストしていない投稿を取り消しても何も起きないため
  - Mastodonは取り消しを受け付けても、前のブーストを裏の処理で後から消し、消し終えるまでは付け直しを422（既にブーストされています）で断る。取り消した直後のブーストが422で断られたら、間をおいて送り直し、何度か送り直しても断られたら失敗にする。ブーストは送り直しても結果が変わらないので、自動で送り直してよい
- ブーストできない投稿（他人のフォロワー限定の投稿や、個別の投稿）は飛ばす
- 公開範囲は、ブーストの公開範囲の設定に従う
- 1件ごとに、`TuningCatalog`の間隔をあける。Mastodonは、ほかのサーバーへ送るブーストの日時（`published`）を秒までしか載せず、受け取ったサーバーはその日時で並べるため、同じ1秒の中に続けて送ると、ほかのサーバーのフォロワーには順番が入れ替わって届きうる
- 進んでいる間は、出たままのチップに「ブースト中」と、済んだ件数と全体の件数を出す。押すと止めるかを確かめる。止めたら、済んだ分はそのまま残す
- 失敗したら、そこで止める。先へ進めると順番が崩れるため。数秒で消えるチップで何件目で失敗したかを知らせ、押すと理由と「続きからブースト」を出す。続きは、失敗した投稿から選んだ順に進める。取り消したあとのブーストで失敗した投稿は、続きでブーストし直す
- 1件ずつの結果は、ふだんのブーストと同じく、その投稿を出しているすべての一覧に反映する

### 共有

- 選んだ投稿の本文とメディアを、共有のシートに1回で渡す。投稿ごとにシートを出すと、件数だけ選び直すことになるため
- 本文は、選んだ順に、各投稿の本文を空行でつないだ1つの文章にする。本文は「テキストをコピー」と同じく、書式を落とし、カスタム絵文字を`:shortcode:`にした文字にする。本文のない投稿は飛ばす
- メディアは、選んだ順に、投稿ごとに添付ファイルの順で、元のファイルを渡す。メディアの種類（画像、動画、GIF、音声）は問わない
- メディアは、ふだんの共有と同じく落としてから渡す。落としている間は、出たままのチップに「ダウンロード中」と、落とし終えた数と全体の数を出し、押すと止めるかを確かめる。落とせなかったら共有のシートを出さず、数秒で消えるチップで知らせ、押すと理由を出す
- 共有のシートは、いちばん手前の画面から出す。選び終えるとツールバーは消え、落としている間に画面を移ることもあるため
