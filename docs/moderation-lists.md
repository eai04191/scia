# ミュートとブロックのリスト

ミュートしたユーザー、ブロックしたユーザー、ブロックしたドメインを見て解除する画面と、ドメインのブロックで、作者が決めたこと。

## 入口

- アカウントの画面の、サーバーでの設定のセクション（フィルターと同じセクション）に、フィルターのすぐ下へ「ミュートしたユーザー」「ブロックしたユーザー」「ブロックしたドメイン」の順に並べる。フィルターと同じく、アカウントの画面を閉じずにその中で進む（[account-screen.md](account-screen.md)）
- URLは`scia://accounts/<muted|blocked>`と`scia://domain-blocks`。どれも、フィルターと同じく単独のシートで出す

## ミュートしたユーザーとブロックしたユーザー

- [account-list.md](account-list.md)の人のリストの画面を使い回し、`GET /api/v1/mutes`と`GET /api/v1/blocks`で読む。並びはサーバーが返すとおりにし、続きは応答の`Link`ヘッダーの`next`から読む
- 行を押すと、お知らせのリンクと同じく、アカウントの画面（URLで開いたときはシート）を閉じてから、タブの画面にその人のプロフィールを開く。長押しでユーザーのメニューを出す
- 行を左へスワイプすると「ミュートを解除」「ブロックを解除」を出す。確かめずに送る。ユーザーのメニューの解除と同じ送り方を通すので、済んだことのチップ、ホームと通知のタイムラインへ足すのを再開すること、キャッシュした関係の更新も同じになる
- 解除をサーバーが受け付けたら、使う人の操作で行が消えるので、標準の削除の動きで行を閉じる。長押しのユーザーのメニューから解除したときも、同じく行を閉じる。解除できなかったら、チップで理由を知らせ、行を残す
- だれもいなければ「ミュートしているユーザーはいません」「ブロックしているユーザーはいません」と出す

## ブロックしたドメイン

- `GET /api/v1/domain_blocks`で読み、ドメインの名前だけを並べる。並びはサーバーが返すとおりにし、続きは`Link`ヘッダーの`next`から読む。最後の行が見えたら続きを読む
- 右上の＋で、ドメインを入れるアラートを出す。アラートには、ブロックで起きること（そのサーバーの人の投稿と通知が表示されなくなり、そのサーバーの人とのお互いのフォローが外れる）を書き、赤い「ブロック」で送る。外れたフォローは解除しても戻らないので、入れることと確かめることを1つのアラートで兼ねる
  - 入れた文字は、`https://`、`/`から後ろ、`@user@`を除いて小文字にしてから送る（`DomainInput.normalize`）。URLやハンドルを貼っても、そのドメインになる。何も残らなければ「ブロック」は無効になる
  - 受け付けたら、並びの先頭に足す。ブロックできなかったら、理由を出してから、入れた文字を残したまま入力に戻す
- 行を左へスワイプすると「ブロックを解除」を出す。確かめずに送り、受け付けたら行を外す。解除できなかったら、アラートで理由を出し、行を残す
- ドメインがなければ「ブロックしているドメインはありません」と出す
- ブロックや解除を受け付けたら、キャッシュした関係のうち、そのドメインの人と、ハンドルをキャッシュしておらずドメインを見分けられない人の分を忘れる（`RelationshipCache.forgetRelations`）。国際化ドメインは、Mastodonが`acct`ではUnicode、ドメインのブロックではPunycodeで書くので、どちらも国際化ドメインなら同じかもしれないとみなして忘れる（`UserHandle.mayBeSameDomain`）。ユーザーのメニューはキャッシュした関係でその場で項目を組み、開いている間は再読み込みしても差し替えないため、残すと前の項目が出る。忘れた人のメニューは、開いたときにもともと送る再読み込みを待ってから項目を出すので、通信は増えない
  - 開いているプロフィールのうち、そのドメインの人のものには、関係を再読み込みして入れ、フォロワー数のためにアカウントも再読み込みする。Mastodonはお互いのフォローを外すので、残すとフォローのボタンが前のままになる。そのドメインの人のプロフィールを開いているときだけ、通信が増える

## ユーザーのメニューの「ドメインをブロック」

- ユーザーのメニューの関係の項目に、ほかのサーバーの人にだけ「（ドメイン）をブロック」を出す。同じサーバーの人の`acct`にはドメインがなく、自分のサーバーはブロックできないため。既定の並びでは「ブロック」のすぐ下に置く
- 関係の`domain_blocking`がtrueなら「（ドメイン）のブロックを解除」にする
- ブロックは、ドメインを入れるアラートと同じ本文で確かめてから送る。解除は確かめない
- ドメインのブロックのAPIは空の応答を返すので、送ったあとに相手との関係を再読み込みし、キャッシュした関係と開いているプロフィールに反映する。その前に、ドメインの画面と同じく、そのドメインの人とドメインを見分けられない人の関係を忘れる。ほかのアカウントとして送ったときは、そのアカウントでキャッシュした関係を、そのアカウントで見つけた人のハンドルで見分ける。ブロックしたドメインのリストを読んであれば、再読み込みする
- Mastodonは、ドメインをブロックすると、そのドメインのフォロワーを外すだけでなく、APIのドキュメントと違い、そのドメインの人への自分のフォローも外す（`AfterBlockDomainFromAccountService#remove_follows!`）。ブロックと同じく、開いている相手のプロフィールのフォロワー数と、自分のプロフィールの紹介しているユーザーを再読み込みする
- ホームと通知のタイムラインから、そのドメインの人の投稿は除かない
