# リスト

リストを作る、変える、消す、人を足したり外したりすることについて、作者が決めたこと。リストのタイムラインをタブに置いて流す決まりは[tabs.md](tabs.md)の「リスト」にある。

- リストの数と名前の長さの上限（Mastodonの既定では50個と256文字）はAPIで返らないので、手元では止めない。サーバーが断って返した理由を、失敗したときの表示に出す
- リストに足せるのは、フォロー中かフォローをリクエスト中の人と、自分だけ。Mastodonがそう決めているため

## 作る

- タブの設定の並びの下に「リストを作成」を置く。押すと名前を入れるアラートを出し、作ったリストを並びに足す。リストはもともとタブの並びに出ているので、作ったものをその場で並べ替えたり、表示を切り替えたりできる
- ユーザーのメニューの「リストに追加」のシートの中でも作れる。作ったリストには、そのままその人を足す。作れて足すのだけに失敗したら、作ったリストは並びとシートに残してチェックマークを付けず、チップで理由を知らせる。もう一度作り直さず、シートでそのリストを押せば足し直せるようにするため
- 作ったリストは、「タブに追加」と同じく、有効にして切り替えタブの末尾に入れる。作るのはすぐ使うためで、ふだん並べているタブは押しのけない。webなどで作ったリストを、無効にして最後のリストの後ろに足す決まり（[tabs.md](tabs.md)の「リスト」）とは分ける
- 作ったリストは、自分のリストを読み直すのを待たずに並びに出す
- 作れなかったら、アラートで理由を出し、閉じると入れた名前を残したまま名前の入力に戻す。チップで知らせるだけでは、入れた名前が失われるため

## 変える

リストのタイムラインの右上のボタンのメニューで、そのリストを変える。

- 「名前を変える」: 名前を入れるアラートを出す。アプリの中で変えた名前は、使う人が名前を付けたタブと同じく、起動し直さなくてもすぐ、タブバー、切り替えタブの見出しのメニュー、設定の並び、タイムラインの見出しに出す
- 「メンバー」: メンバーの画面を開く（「メンバー」にある）
- 「返信の表示」: どの返信をリストに流すかを、サブメニューで「フォロー中のユーザー全員」「リストのメンバー」「表示しない」から選ぶ。今の設定をチェックで示す
- 「ホームに出さない」: メンバーの投稿をホームに流さないかを切り替える。今の設定をチェックで示す
- 「削除」: 「削除する」にある
- 返信の表示とホームに出さないを変えても、もう読み込んであるリストとホームの行はそのまま残す。サーバーが変えるのはこれから届く投稿だけで、あとから除くと読んでいる行が動くため
- 名前を変えられなかったら、作れなかったときと同じく、アラートで理由を出して名前の入力に戻す
- 返信の表示とホームに出さないを変えられなかったら、押し直せば済むので、チップで理由を知らせ、メニューの中身は元の設定のままにする

## 削除する

- リストのタイムラインの右上のメニューの「削除」と、タブの設定の並びかアカウントの画面の「リスト」で、リストの項目を左へスワイプして出す「削除」で消す
- 消すとメンバーの設定も戻せないので、確かめてから消す
- 消したら、自分のリストを読み直すのを待たずに並びから外し、ストリーミングの購読を止める。リストのタイムラインを開いていたら、先頭のタブへ移る
- 消せなかったら、チップで理由を知らせ、並びは変えない

## メンバー

- メンバーの画面は、[account-list.md](account-list.md)の人のリストの画面を使い回し、`GET /api/v1/lists/:id/accounts`で読む。見出しの下にリストの名前を出す
- 行を左へスワイプすると「外す」を出す。外すのをサーバーが受け付けたら、使う人の操作で行が消えるので、標準の削除の動きで行を閉じる。外せなかったら、チップで理由を知らせ、行を残す
- 右上の＋で、フォローしている人に絞って探し（`api/v1/accounts/search`の`following=true`）、選んだ人を足す。足せる人だけを出すため。フォローしていない人は、ユーザーのメニューの「リストに追加」から足す
  - 探した結果では、もう入っている人にチェックマークを付け、押すと外す。足し間違えたときに、その場で戻せるようにするため
  - 足すか外すのに失敗したら、チップで理由を知らせ、チェックマークを変えない
- メンバーがいなければ「メンバーはいません」と出す

## 「リストに追加」

ユーザーのメニューの「リストに追加」で、その人をどのリストに入れるかを選ぶ。

- 選ぶと、自分のリストを並べたシートを開く。その人が入っているリストを`GET /api/v1/accounts/:id/lists`で読み、チェックマークで示す。読む間は読み込み中の表示を出す
- リストを押すたびに、その場で足したり外したりする。押したらすぐチェックマークを変え、失敗したら元に戻してチップで理由を知らせる
- 自分は、フォローせずにそのまま足す。自分かどうかは、ユーザーのメニューと同じくIDで決める
- 自分ではなく、フォローもリクエストもしていない人のリストを押したら、Mastodonのwebと同じく、「リストに追加するにはフォローが必要です」と確かめ、「フォローしてリストに追加」でフォローしてから足す。承認制の相手は、リクエスト中のまま足す
- ブロックしているか、されている相手は、フォローできず足せないので、リストを押せなくし、理由を書く
- リストがなければ、「リストを作成」だけを出す
