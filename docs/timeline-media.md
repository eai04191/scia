# 一覧の添付ファイルの並べ方

投稿の添付ファイルを、本文の下に大きく並べるか、本文の右に小さな正方形で出すかで、作者が決めたこと。右に出すと、メディアの多いタイムラインでも1画面に多くの投稿が入る。

## 設定

- 「投稿の見た目」の「メディア」に「並べ方」を置き、「本文の下に大きく」と「本文の右に小さく」から選ぶ。既定は「本文の下に大きく」
- 「本文の右に小さく」のときだけ使う値として、「右に並べるときの大きさ」（正方形の一辺）を足す。既定は64pt
- 本文とサムネイルの横のすき間には「本文とのあいだ」を使う。右に並べるときは本文との縦のすき間がないため、項目を分けない

## 置き方

- 名前の行は全幅のままにし、時刻も右端に置く
- サムネイルは右端に置き、上端を本文の1行目の字面の上端にそろえる。本文のない投稿でも右端に置き、上端は本文があるときと同じ位置にする
- 本文は、右にサムネイルとすき間の分をあけて折り返す
- 行の高さは、本文の下端とサムネイルの下端の、下にあるほうで決める。本文が短くても、サムネイルの分は行を伸ばす
- 投票、リンクカード、Xの投稿、フィルターの注記は、本文とサムネイルのどちらよりも下に、全幅で置く
- 注意書きのボックスは全幅のままにする。開いたあとは、本文の横にサムネイルを出す。閉じている間は、本文の下に並べるときと同じく出さない
- 画像は正方形に収まるよう、焦点に合わせて切り抜く

## 2つ以上のとき

- 重なりのすべてを、一辺の正方形の中に収める。はみ出させると、枚数で本文の折り返しの幅が変わるため
- 1つ目を手前に置き、2つ目と3つ目のサムネイルを右上へ少しずつずらして奥にのぞかせる。4つ目より後ろは3つ目の下に隠れているものとして描かない。手前の1つは、ずらした分だけ小さくする
- 写真の白いフチと回転は付けない。投稿欄のカプセルの紙焼きの写真は、書きかけの添付の見立てで、一覧の投稿には持ち込まない
- 枚数のラベルは付けない。1つか2つ以上かは重なりで分かる

## 操作

- タップすると、1つ目からビューアを開く。ほかの添付ファイルは、ビューアでめくって見る
- ビューアを閉じるときは、何番目を見ていても、手前の1つの位置へ縮めて戻す。奥のサムネイルはほとんど隠れていて、そこへ戻しても行き先が見えないため。2つ目より後ろを見ていたときに、着いたところで手前の画像へ替わるのが不自然に見えないかは、まだ試していない。閉じる時間をチューニングで伸ばして録画し、作者が見て決める
- 長押しすると、手前の1つのメディアのメニューを出す

## 状態の表示

- 閲覧注意、フィルター、非表示のぼかしは、重なり全体を1つでぼかし、目の記号だけを出す。サムネイルは小さく文字が入りきらないため、1列に並べるときと同じく文言は出さない
- ALTやGIFのバッジと再生アイコンは、手前の1つにだけ出す

## 当てはめる範囲

- 投稿の行を使うところすべて（各タブ、スレッド、プロフィール、ブックマークとお気に入り）に当てはめる
- 引用とXの投稿の囲みの中のメディアは、本文の下に並べたままにする。囲みは元の投稿の見た目を写すものなので
- 編集履歴と通知の引用は、今の小さな正方形の1列のままにする
