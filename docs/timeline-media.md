# 一覧の添付ファイルの並べ方

投稿の添付ファイルを、本文の下に大きく並べるか、本文の右に小さな正方形で出すかで、作者が決めたこと。右に出すと、メディアの多いタイムラインでも1画面に多くの投稿が入る。

## 設定

- 「投稿の見た目」の「メディア」に「並べ方」を置き、「本文の下に大きく」と「本文の右に小さく」から選ぶ。既定は「本文の下に大きく」
- 「本文の右に小さく」のときだけ使う値として、「右に並べるときの大きさ」（正方形の一辺）を足す。既定は64pt
- 本文とサムネイルの横のすき間には「本文とのあいだ」を使う。右に並べるときは本文との縦のすき間がないため、項目を分けない

## 置き方

- 名前の行は全幅のままにし、時刻も右端に置く
- サムネイルは右端に置き、上端を本文の1行目の字面の上端にそろえる。本文のない投稿でも右端に置き、上端は本文があるときと同じ位置にする
- 本文は、右にサムネイルとすき間の分をあけて折り返す
- 行の高さは、本文の下端とサムネイルの下端の、下にあるほうで決める。本文が短くても、サムネイルの分は行を伸ばす
- 投票、リンクカード、Xの投稿、フィルターの注記は、本文とサムネイルのどちらよりも下に、全幅で置く
- 注意書きのボックスは全幅のままにする。開いたあとは、本文の横にサムネイルを出す。閉じている間は、本文の下に並べるときと同じく出さない
- 画像は写真の中の正方形に収まるよう、焦点に合わせて切り抜く

## 写真の見た目

- 添付ファイルは、1つでも2つ以上でも、投稿欄のカプセルと同じく、白いフチの付いた紙焼きの写真に見立てて出す。重ね方（1つ目を手前に3つ目までを重ねること、回す向き、のぞかせる側、2つの影）は、[compose.md](compose.md)の「書いていないときの1行」と同じにする。投稿欄を勢いよく閉じたときに散らばらせる動きは使わない
- 重なりのすべてを、回した写真の角まで含めて、一辺の正方形の中に収める。はみ出させると、数によって本文の折り返しの幅が変わるため
- 回す角度、ずらす量、影の濃さは、投稿欄とは別のチューニングの項目で決める。初めの値は、投稿欄の値を写真の大きさの比で大きくしたものにする。フチの太さ、角の丸み、影の広がりは、写真の大きさによらず投稿欄の写真と同じ値にする。現実の紙焼きの写真は、大きく焼いてもフチや角が大きさに比例して太くならず、影の広がりは大きさではなく下の面からの浮きで決まるため
- 4つ目より後ろは3つ目の下に隠れているものとして描かない。枚数のラベルは付けない。1つか2つ以上かは重なりで分かる

## 操作

- タップすると、1つ目からビューアを開く。ほかの添付ファイルは、ビューアでめくって見る
- ビューアを閉じるときは、見ていた添付ファイルの写真の位置へ縮めて戻す。4つ目より後ろは、3つ目の写真の位置にあるものとして、そこへ戻す。手前の写真へ戻すと、着いたところで手前の画像に替わって見えるため
- ビューアを開いている間と、開閉で画像を動かしている間は、起点の写真をフチごと隠す。画像のない白い枠を一覧に残さず、写真を持ち上げたように見せるため
- 開閉で動かす画像は、起点の写真の角度から、まっすぐになるまで回しながら動かす。まっすぐな四角と回した写真が、開き始めと閉じ終わりに切り替わって見えないようにするため
- 開閉で動かす画像にも写真の白いフチを付け、ビューアの画像の位置へ向かうにつれて細くしてなくす。閉じるときは、写真に着くにつれて元の太さに戻す。フチが開き始めに消え、閉じ終わりに急に現れて見えないようにするため。投稿欄のカプセルと列のあいだの動きで、フチをほどくのと同じ
- 長押しすると、手前の1つのメディアのメニューを出す

## 状態の表示

- 閲覧注意、フィルター、非表示のときは、写真のフチと重なりはそのまま見せ、中の画像を読まずにblurhashのぼかしで描き、手前の写真に目の記号だけを出す。リンクカードの小さなサムネイルと同じ出し方。サムネイルは小さく文字が入りきらないため、文言は出さない
- ALTやGIFのバッジと再生アイコンは、手前の1つにだけ出す

## 当てはめる範囲

- 投稿の行を使うところすべて（各タブ、スレッド、プロフィール、ブックマークとお気に入り）に当てはめる
- 引用とXの投稿の囲みの中のメディアは、本文の下に並べたままにする。囲みは元の投稿の見た目を写すものなので
- 編集履歴と通知の引用は、今の小さな正方形の1列のままにする
