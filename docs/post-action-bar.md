# アクションバー

投稿の下に、返信やお気に入りなどのボタンを横に並べるアクションバーについて、作者が決めたこと。

## 出し方

- 出し方は2つあり、どちらも選べる
  - いつも出す: 「投稿の見た目」の分類「アクションバー」の「アクションバーを常に表示」で切り替える。既定はオン
  - 開く: 「操作」の「投稿」のタップか長押しで「アクションバーを開く」を選ぶと、その投稿の下に引き出しとして開く。決まりは「引き出し」にある
- 出すのは、リストのアイテムのうち投稿だけにする。タイムライン、プロフィール、リスト、ハッシュタグ、ブックマーク、お気に入り、検索、スレッドの投稿（中心の投稿を含む）が当たる
- 通知と、投稿の中の引用の囲みには出さない
  - 通知の操作では「アクションバーを開く」を選べない
  - 引用の囲みは投稿の操作に従うので、「アクションバーを開く」を選んでいると、押せない項目と同じく、数秒で消えるチップでその対象では行えないことを知らせる
- 「投稿の見た目」のプレビューの見本の投稿にも、いつも出す設定のときは出す。「アクションバー」の分類の見本には、いつも出す設定でなくても出す。ボタンは押しても何もしない
- いつも出しているときは、「アクションバーを開く」は何もしない

## ボタン

- 並べるボタンは、設定の「操作」の「投稿」の「アクションバー」で選ぶ。投稿のメニューの項目と、投稿のメニューを開く「メニュー」から選ぶ。既定の並びは、返信、ブースト、お気に入り、ブックマーク、メニュー
- 並びの画面は、メニューの並びの画面と同じ作りで、1つの節に全部の項目を並べ、スイッチを入れた項目を上から順にアクションバーの左から並べる。「その他」の境目と区切り線は置かない。「カスタマイズ」は並べない
- ボタンを押したら、タップに割り当てた1項目と同じ組み方で行う（[object-actions.md](object-actions.md)の「項目を行う」）。確かめてから送る、チップで知らせる、サブメニューの中身を出す、が同じになる。「メニュー」は、投稿を長押ししたときと同じ投稿のメニューを、ボタンから出す
- 押せない項目（ほかの人の投稿の編集、ブーストできない投稿のブーストなど）と、その投稿では出ない項目は、ボタンを薄く描き、押すとチップでその対象では行えないことを知らせる
- アクションバーを出している投稿のメニューからは、アクションバーに並べた項目を除く。押せずに薄く描いている項目も除く。アクションバーの「メニュー」のボタンで出すメニューも同じ。引き出しを閉じている投稿や、アクションバーを出さない投稿と通知では、除かずに出す。ほかのメニューの中から開く投稿のメニュー（メディアのメニューの「投稿」など）と、投稿の中の引用の囲みのメニューは、アクションバーが操作する投稿のメニューではないので除かない
- メニューから除くかは、設定の「操作」の「投稿」の画面で、「メニュー」と「アクションバー」の入り口の下の節「アクションバーを出している投稿のメニュー」のスイッチで切り替える。メニューとアクションバーの両方に関わるため。「アクションバーにある項目を表示」をオフにすると上の決まりで除き、既定はオフ。「ブーストとお気に入りの長押しの項目を表示」をオフにすると、並べたブーストとお気に入りのボタンの長押しで出す項目も、同じ決まりで除く。既定はオフ。2つは別々に効く
- ブーストとお気に入りのボタンは、長押しでメニューを出す。ブーストは「公開範囲を選んでブースト」「引用」「ブーストした人」、お気に入りは「お気に入りした人」を並べる。項目は投稿のメニューと同じ組み方で組み、その投稿で出ない項目は出さない。出す項目がなければメニューを出さない
- ほかのボタンは押したときだけ行い、長押しでは何もしない。どのボタンの上の長押しでも、投稿の長押しの操作はしない
- ボタンを長押しして出すメニューは、ボタンを持ち上げず、押した位置にメニューだけを出す
- アイコンは、投稿のメニューの項目と同じ記号にする。状態を持つ項目は、した状態を記号の塗りで示す（お気に入り、ブックマーク）。塗りの記号がない項目（ブースト）は色だけで示す。状態が変わったときは、記号を変形でつなぐ
- したお気に入りとブーストのボタンは、光と同じ色で描く。ブーストは緑、お気に入りは、ダークでは黄色、ライトでは「お気に入りとブーストの光」で選んだ色にする。投稿の光（[reaction-glow.md](reaction-glow.md)）は、アクションバーを出していても残す。したブックマークのボタンは、記号を塗り、赤（`systemRed`）で描く
- 件数: 返信、ブースト、お気に入りのボタンには、アイコンの右に件数を添える。0なら添えない。「アクションバー」の分類の「件数を表示」で切り替え、既定はオン。件数は時刻と同じ文字で描き、1万より小さければ桁区切りで出し、1万からは「1.2万」「123万」のように万、億、兆の単位で縮める。単位の前の整数の部分はすべて出し、整数の部分が1桁のときだけ小数を1桁添える。桁区切りのままでは、100万を超える数が幅に入りきらず切れたため。読み上げでは縮めずに正確な数を読む。ほかの人がお気に入りやブーストをしても、Mastodonのストリーミングでは届かないので、自分がしたときと読み直したときにだけ変わる
- 読み上げでは、ボタンごとに項目の名前、件数、した状態（「済み」）を読む

## 並べ方

- アクションバーは投稿の一番下（絵文字のリアクションの列とフィルターの注記の下）に置き、本文の列の左端から右端まで、ボタンを同じ幅で並べる。ボタンの中は、アイコンを左に寄せ、件数を右に添える
- ボタンが多いなどで、それでも件数が幅に入りきらないときは、件数の文字を小さくする。小さくしても入らないボタンでは、件数を出さない。読み上げでは件数を読む
- 「アクションバー」の分類の数値の項目は、本文とのあいだ、アイコンの大きさ、ボタンの上下の余白。ボタンの幅と、アイコンに上下の余白を足した高さに加え、バーの上の「本文とのあいだ」と下の「下の余白」の何も受けない空きも、アイコンの中心から上下22pt（合計44pt）まで押せる。見た目と余白の値は変えない

## 引き出し

- 「アクションバーを開く」で、その投稿の下にアクションバーを開く。開いている投稿で同じ操作をすると閉じる
- 同時に開けるのは1つだけにする。別の投稿で開くと、前に開いていた投稿のアクションバーは閉じる
- スクロールしても閉じない。使う人が閉じるまで開いたままにする
- 開いた投稿は、そのタイムラインの中で覚える。タイムラインを閉じるか、アプリを起動し直すと、閉じた状態に戻る
- 開閉は使う人の操作の結果で、見えている投稿の高さが変わるので、[vision.md](vision.md)の「タイムラインの動き」に従い、押した投稿の位置を保って、下のアイテムごと動かしてつなぐ。開くときは、投稿を上から下へ切り抜いて広げ、アクションバーを現す。閉じるときは、アクションバーを残したまま、まわりのアイテムが詰めて覆う
- 動きの時間は`TuningCatalog`の項目で選ぶ
- 動きの途中でも、スクロール、別の投稿で開く、閉じる、アクションバーのボタンを受け付ける
