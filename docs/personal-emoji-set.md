# 絵文字の個人セット

Fedibirdの、自分で選んだ絵文字をカテゴリーに分けて並べたセットを、絵文字ピッカーに出すときに、作者が決めたこと。Mastodonにはない機能。APIはFedibirdのソース（[fedibird/mastodon](https://github.com/fedibird/mastodon)の`docs/personal_emoji_sets.md`と`app/lib/personal_emoji_sets/stock.rb`）で確かめた。

## 対象のサーバー

- `instance`の`fedibird_capabilities`に`personal_emoji_sets`があるサーバーでだけ読む
- サーバー情報が読めないうちや読めなかったときは、対応していないものとして扱う

## 読む値

- `GET /api/v1/emoji_sets/personal/stock`の`stock.categories`を読む。カテゴリーの`id`と`name`、絵文字ごとの`selection`（カスタム絵文字かどうか、ショートコード、Unicodeの絵文字そのもの）、`image`（静止画と動く画像のURL、幅と高さ）、`search`（検索の語）を使う
- 使えなくなった絵文字は、サーバーが除いて返す
- カスタム絵文字は、応答の画像のURLで描く。個人セットには、管理者がピッカーに出さないと決めたカスタム絵文字も入れられ、それは`api/v1/custom_emojis`のリストから選ぶ対象にならないため
- Unicodeの絵文字は、肌の色を付けたものも、応答の文字のまま並べて入れる
- カテゴリーの`heading`を、見出しとして読む。Fedibirdの設定で、先頭の絵文字、名前の先頭の1文字、カテゴリーの中の絵文字の1つから選べ、サーバーが選んだ結果を返す。`image`があれば、その`alt`（カスタム絵文字は`:shortcode:`、Unicodeの絵文字はその文字）でカテゴリーの中の絵文字を探して見出しにし、なければ`text`の1文字を見出しにする
- 絵文字の大きさ（`picker_emoji_size`）は読まない

## 並べ方

- 絵文字ピッカー（[compose.md](compose.md)の「絵文字ピッカー」）に、カテゴリーごとのグループとして、最近使った絵文字のあと、サーバーのカスタム絵文字の前に並べる。カテゴリーの順と、中の絵文字の順は、サーバーが返すとおりにする
- 空のカテゴリーは出さない
- ピッカーの下に並ぶグループのボタンのアイコンは、カテゴリーの見出しにする。絵文字ならその絵文字を、マスと同じ画像と絵文字のスタイルで描く。1文字なら、時計などの記号のアイコンと同じ色で描く
- 投稿欄、リアクション、お知らせのリアクション、プロフィールの編集のどの絵文字ピッカーにも出す。投稿するアカウントを替えたときと、「別のアカウントで」のリアクションでは、そのアカウントの個人セットを出す
- 検索では、個人セットの絵文字のうち、サーバーが返す検索の語（ショートコード、別名、読み）に検索語を含むものを、ほかの結果の前に並べる。ひらがなとカタカナ、全角と半角、大文字と小文字は区別しない。サーバーの検索の語には合わず、ほかの検索で見つかった絵文字は、個人セットにあっても順を変えない
- 個人セットから選んだ絵文字も、最近使った絵文字に出す

## 再読み込み

- 書き始めたときと、絵文字ピッカーを開くたびに再読み込みする。webやほかの端末で編集した並びを出すため。端末には残さない
- 開いている間に再読み込みしたものが届いたら、その場で並べ直す。カスタム絵文字のリストは開いている間は並べ直さないが、個人セットは使う人が自分で変えたものなので、選択しようとしている絵文字がずれることより、変えたとおりに並ぶことを優先する。前と同じ内容なら並べ直さない
- 読めなかったときは、前に読んだものを出し、何も知らせない。まだ読めていなければ、個人セットのグループを出さない

## 扱わないこと

- 個人セットの編集（カテゴリーや絵文字の追加、並べ替え）。Fedibirdのwebの設定で行う
