# 機能

Sciaでできることの一覧

## タイムラインタブ

任意に追加したり並べ替えたりできるタブの一覧

- ストリーミング
  - ホーム・ローカル・連合・リスト・フォローしているハッシュタグ
- ハッシュタグ
- 特定ユーザーの特定ハッシュタグ
- ブックマーク
- お気に入り

## タイムライン機能

- 新着が届いても、読んでいる位置を動かさない
- 一番上にいるときは新着に追従
- 前回読んだ位置からの再開（ほかの端末と同期）
- 通信が切れたりアプリに戻ったりしたあとの、取りこぼしのない読み込み
- 引っぱって読み直す

## 投稿の表示

- カスタム絵文字
  - アニメーション対応
- HTMLレンダリング
  - 引用
- 注意書き（CW）
- サーバーのフィルター（警告、非表示）
- 投票
- リンクのプレビューカード
- スレッド
- 編集履歴
- 翻訳
- 本文の文字を選んでコピー

## 投稿への操作

- 返信
- ブースト
- お気に入り
- ブックマーク
- 公開範囲を選んでブースト
- 引用
- お気に入りした人とブーストした人の一覧
- リンクのコピー、共有、ブラウザで開く
- 会話のミュート
- 自分の投稿の編集、削除、プロフィールへの固定

## 投稿する

- タイムラインを見ながら書ける投稿欄
- メディアの添付
  - 代替テキスト
  - 閲覧注意
  - トリミング
  - 動画をGIFとして送る
  - 送る前に縮める
  - 位置情報の削除
  - クリップボードから添付
- メンション・ハッシュタグ・絵文字の入力補完
- 絵文字・カスタム絵文字パレット
- 注意書き（CW）
- 投票
- 公開範囲
- 投稿の言語
- 予約投稿
- リンクにページタイトルを付ける

## メディア表示

- フォーカス
- 閲覧注意のぼかし
- ALT、GIF、HDRのバッジ
- ビューア
  - 画像、動画、GIF、音声
  - 代替テキストの全文と翻訳
  - 画像の文字の読み取り（Live Text）
  - 写真に保存、共有
- メディアの情報（解像度、形式、長さなど）
- HDRの写真と動画の表示

## 通知

- ストリーミング
- 同じ投稿への反応をまとめて表示
- 通知の削除
- フォローリクエストの承認と拒否
- ステータスバーに通知を流す

## プロフィール

- 投稿の一覧（返信とブーストの表示の切り替え）
- 固定された投稿
- フォローとフォロワーの一覧
- アイコンとヘッダー画像の拡大
- 自分にしか見えないメモ
- 自分のプロフィールの編集

## ユーザーへの操作

- フォロー（ブーストの表示、投稿の通知）
- ハンドルのコピー・リンクのコピー・共有・ブラウザで開く
- ミュート
- ブロック
- 通報

## アカウント

- 複数アカウントの切り替え
- ログインするサーバーの入力補完

## カスタマイズ

- 投稿の見た目（文字の大きさ、余白、表記など）
- 通知の見た目
- タブの選択と並べ替え
- 長押しのメニューの項目と並び
- タップと長押しで開くもの
- リンクを開くブラウザ（既定のブラウザ、アプリ内のSafari）
- 絵文字をTwemojiで表示
- 漢字の字形（日本語・繁体字・簡体字・韓国語）
- 投稿欄を隠す
- アプリのアイコン

## 通信とストレージ

- モバイル通信で画質を抑える
- Wi-Fiで画像を先読み
- ストレージの内訳表示
- キャッシュの削除
- 接続の状態の確認

## ほかのアプリとの連携

- 写真アプリなどの共有から添付
- Safariの共有から引用して書き始める
- `scia://profile/<user@domain>`でプロフィールを開く

## iPadとMac

- ウィンドウの大きさの自由な変更
- Macでは、ビューアを別のウィンドウで開く
- ハードウェアキーボードのnで書き始める
