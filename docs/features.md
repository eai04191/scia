# 機能

Sciaに入っている機能の一覧。細かい決まりは、見出しの横に置いた各機能のdocsにある。

## アカウント

- OAuthでのログイン
  - 打ったアドレスに合うサーバーの候補
  - Safariのログイン状態を使わないプライベートなログイン
- 複数アカウントの切り替え
- トークンが無効になったときのログインし直しの案内

## タイムライン（[tabs.md](tabs.md)）

- ストリーミング
  - ホーム
  - ローカル
  - 連合
  - リスト
  - フォローしているハッシュタグ
  - 通知
- RESTで読み直すタブ
  - ユーザーのハッシュタグ
  - ブックマーク
  - お気に入り
  - 予約投稿
- タブの選択と並べ替え、あふれた分の切り替えタブ
- 新着の挿入
  - 最上部での追従
  - 読んでいる途中は溜めて件数を表示
- 切断・復帰時の取りこぼしの補完
  - ギャップの自動読み込み
- 既読位置の同期（markers）
- 引っぱって読み直す（[pull-status.md](pull-status.md)）
  - ストリーミングとRESTの状態の表示
- タブの再タップで最上部へ戻る

## 投稿の表示

- 本文のリッチテキスト
  - リンク、メンション、ハッシュタグ
  - カスタム絵文字（アニメーション対応、[animated-custom-emoji.md](animated-custom-emoji.md)）
  - 絵文字だけの本文を大きく表示
  - Twemojiへの切り替え
  - 漢字の字形の選択
- 注意書き（CW）の折りたたみ
- サーバーのフィルター（[filters.md](filters.md)）
  - 「隠す」は出さない
  - 「警告」は折りたたむ
- 投票の表示と投票（[poll.md](poll.md)）
- 引用の表示（[quote.md](quote.md)）
- リンクカード（[link-card.md](link-card.md)）
  - カードのない投稿の取り直し
  - 閲覧注意の投稿でのぼかし
- 返信のラベルと線（[thread.md](thread.md)）
- 公開範囲のアイコン
- 編集済みのアイコンと編集履歴
- お気に入りとブーストの光（[reaction-glow.md](reaction-glow.md)）
- 読めなかった投稿を「表示できない」行で表示
- 「投稿の見た目」の設定（[appearance.md](appearance.md)）

## メディア（[timeline-media.md](timeline-media.md)）

- 一覧のサムネイル
  - 投稿者が付けた焦点に合わせた切り抜き
  - 閲覧注意のぼかし（blurhash）
  - ALT、GIF、HDRのバッジ（[hdr-display.md](hdr-display.md)）
  - 本文の右に重ねる並べ方
- ビューア
  - 画像、動画、GIF、音声
  - スワイプで閉じる
  - 代替テキストの全文と翻訳
  - Live Text
  - 写真に保存、共有
- HDRの明るさの設定（ビューア以外とビューアで別々）
- 画像の先読み（[image-loading.md](image-loading.md)）

## 投稿欄（[compose.md](compose.md)）

- タブバーの上に置くインライン投稿欄
  - 書いていないときのカプセル
  - 展開
- 投稿、返信、編集、削除
- 補完
  - メンション
  - ハッシュタグ
  - カスタム絵文字と絵文字
- 絵文字のパレット
- メディアの添付（[media-attachment.md](media-attachment.md)）
  - 代替テキスト
  - 閲覧注意
  - 並べ替え
  - トリミング
  - GIFとして送る
  - 端末での縮小と位置情報の削除
  - ペースト、共有から添付
- 注意書き（CW）
- 投票（[poll.md](poll.md)）
- 引用（[quote.md](quote.md)）
- 公開範囲
- 投稿の言語
- 予約投稿
- リンクにタイトルを付ける
- Safariの共有から引用して書き始める

## 投稿への操作

- お気に入り、ブースト（公開範囲を選べる）、ブックマーク
- スレッドの表示（[thread.md](thread.md)）
- お気に入りした人とブーストした人の一覧（[account-list.md](account-list.md)）
- リンクのコピー、共有、ブラウザで開く
- 本文のコピーと文字の選択
- システムの翻訳
- 会話のミュート
- プロフィールへの固定
- 本文のリンクを開く（既定のブラウザかアプリ内のSafari）
- タップと長押しで開くものの設定（[object-actions.md](object-actions.md)）
- メニュー（[menus.md](menus.md)）
  - 投稿、通知、ユーザー、リンク、ハッシュタグ、メディア
  - 並びの設定

## 通知

- 通知タブ（[notification-display.md](notification-display.md)）
  - 同じ投稿への反応をまとめて表示
  - 通知の削除
- フォローリクエストの承認と拒否
- ステータスバーの場所に流す通知（[status-bar-ticker.md](status-bar-ticker.md)）

## プロフィール（[profile.md](profile.md)）

- 投稿の一覧と固定された投稿
- フォロー、フォローの設定
- フォローとフォロワーの一覧（[account-list.md](account-list.md)）
- アイコンとヘッダー画像をビューアで表示
- 個人用のメモ
- ミュート、ブロック、通報
- 自分のプロフィールの編集
- `scia://profile/<user@domain>`で開く

## アプリ内通知（[notices.md](notices.md)）

- 操作の結果と失敗のチップ
- 操作の状況の一覧

## 想定外の応答への備え（[network.md](network.md)）

- 401でアカウントを消さない
- エラーの種類ごとの文言
- ストリーミングにつながらないときのポーリング
- レート制限での待機と、通信が戻ったときの再試行
- サーバーにない機能をセッションの間だけ止める
- 「接続の状態」画面

## 設定

- ストレージの内訳と、キャッシュの削除・見返し
- 通信の節約（モバイル通信で高画質にしない、送る前に縮める）
- 「通知の見た目」
- アプリのアイコン

## iPadとMac

- ウィンドウの大きさの自由な変更
- Macでのビューアの別ウィンドウ
- ハードウェアキーボードのnで書き始める
