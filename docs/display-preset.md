# 表示のプリセット

表示の設定をまとめて持ち、切り替える仕組みについて、作者が決めたこと。まだ実装していない。

## 目的

- 用途で表示を切り替える。家にいるときは画像を大きく表示する、のように。切り替えはショートカットからも行う
- 使う人に適切な既定値を与える。「コンパクト」のようなプリセットを用意し、すべての項目を触らなくてよいようにする

## 値の重ね方

- 表示の値は、次の順に重ね、上の層に値があればそれを使う
  1. アプリの既定値
  2. 組み込みのプリセット
  3. 使う人のプリセット
- 組み込みのプリセットは作者が用意し、使う人は変えられない。アプリの既定値そのままのものも、組み込みのプリセットの1つとして並べる
- 使う人のプリセットは、親にする組み込みのプリセットを1つと、親から変えた項目だけを持つ。親のないプリセットは作らない
- 親にできるのは組み込みのプリセットだけにする。使う人のプリセットを複製すると、同じ親と同じ変えた項目を持つ別のプリセットになる
- 組み込みのプリセットの値を作者があとで変えたら、それを親にする使う人のプリセットも、変えていない項目は新しい値に従う
- 選ぶと今の値に上書きコピーする形にはしない。プリセットを行き来するたびに、それぞれで調整した値が消えるため
- アプリのプリセットは端末に1つ持つ。アカウントには、そのアカウントのプリセットを割り当てられる。割り当てたアカウントは、アプリのプリセットの代わりにそれを使い、アプリのプリセットを切り替えても変わらない。割り当てていないアカウントは、アプリのプリセットに従う
- アカウントごとに項目を1つずつ上書きする層は持たない。アカウントだけ表示を変えるときは、プリセットを作って割り当てる
- 窓を分けて別のアカウントを開いているときは、窓ごとに、そのアカウントが使うプリセットの値で描く
- プリセットを切り替えたときは、読んでいる投稿の位置を保ち、動かさずに描き直す

## プリセットに含める設定

- 「投稿の見た目」「通知の見た目」「メディア」を含める
- 「メディア」の「説明にならない代替テキストを無視」は含めない。見た目ではなく、代替テキストの扱いの設定のため
- 「リンク先の読み込み」は含めない。外部サービスへの通信の同意なので、プリセットの切り替えでオンにしないため

## 既定値から変えた項目

- [appearance.md](appearance.md)の「既定値から変えた項目」の点と「デフォルトに戻す」は、使う人のプリセットでは、親のプリセットの値と比べ、親の値へ戻す

## サーバーの設定に従う項目

- 「アニメーションを再生する」と「カスタム絵文字のアニメーションを再生する」は、オン、オフに並べて「アカウントの設定に従う」を選べるようにする。サーバーのアカウントの設定に従うことを、値がないことではなく値の1つとして持つ。親のプリセットがオンやオフを持っていても、使う人のプリセットから選べるようにするため

## 設定の画面

- 「表示」の先頭に、今使うプリセットの名前を値に出す「プリセット」の行を置き、プリセットを選ぶ画面を開く
- プリセットを選ぶ画面には、組み込みのプリセットと使う人のプリセットを並べ、今使うものにチェックマークを付ける。使う人のプリセットは、複製、名前の変更、削除ができる。組み込みのプリセットは、選ぶことと複製だけができる。親を付け替える手段は置かない
- 使っているプリセットを削除したら、それを使っていたアプリとアカウントを、親の組み込みのプリセットに切り替える
- 「表示」から開いた「投稿の見た目」「通知の見た目」「メディア」で変えた値は、アプリのプリセットに入る。組み込みのプリセットを使っているときに値を変えたら、それを親にした使う人のプリセットを作り、そちらに切り替える。名前は、親の名前に番号を付ける（「コンパクト 2」）
- プリセットを選ぶ画面からは、使う人のプリセットを選ばずに、その中身を変える画面を開ける。アカウントに割り当てただけのプリセットや、今使っていないプリセットを変えるため。プレビューは、変えているプリセットの値で描く
- 設定のトップのアカウントの節に、そのアカウントのプリセットを選ぶ「プリセット」の行を置く。割り当てないこと（アプリのプリセットに従う）も選べる

## ショートカット

- アプリのプリセットを切り替えるアクションと、アカウントのプリセットを割り当てるアクションを、ショートカットに出す。アカウントの割り当てを外すこともできる
- 指したプリセットが削除されていたら、何も変えず、失敗を返す
- プリセットを切り替える手段は、設定とショートカットだけにする。アプリのほかの場所には置かず、`scia://`のURLも作らない
