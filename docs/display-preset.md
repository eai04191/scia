# 表示のプリセット

表示の設定をまとめて持ち、切り替える仕組みについて、作者が決めたこと。まだ実装していない。

## 目的

- 用途で表示を切り替える。家にいるときは画像を大きく表示する、のように。切り替えはショートカットからも行う
- 使う人に適切な既定値を与える。「コンパクト」のようなプリセットを用意し、すべての項目を触らなくてよいようにする

## 値の重ね方

- 表示の値は、次の順に重ね、上の層に値があればそれを使う
  1. アプリの既定値
  2. 組み込みのプリセット
  3. 使う人のプリセット
  4. アカウントごとの上書き
- 組み込みのプリセットは作者が用意し、使う人は変えられない。アプリの既定値そのままのものも、組み込みのプリセットの1つとして並べる
- 使う人のプリセットは、親にする組み込みのプリセットを1つと、親から変えた項目だけを持つ。親のないプリセットは作らない
- 親にできるのは組み込みのプリセットだけにする。使う人のプリセットを複製すると、同じ親と同じ変えた項目を持つ別のプリセットになる
- 組み込みのプリセットの値を作者があとで変えたら、それを親にする使う人のプリセットも、変えていない項目は新しい値に従う
- 選ぶと今の値に上書きコピーする形にはしない。プリセットを行き来するたびに、それぞれで調整した値が消えるため
- 今使うプリセットは端末に1つで、すべてのアカウントに効く。アカウントごとに使うプリセットを割り当てる形にはしない。ショートカットで切り替えたとき、割り当てを優先するとそのアカウントは切り替わらず、切り替えを優先するとアカウントの違いが消えるため
- アカウントごとの上書きは、変えた項目だけを持ち、プリセットを切り替えても残る

## プリセットに含める設定

- 「投稿の見た目」「通知の見た目」「メディア」を含める
- 「リンク先の読み込み」は含めない。外部サービスへの通信の同意なので、プリセットの切り替えでオンにしないため

## 既定値から変えた項目

- [appearance.md](appearance.md)の「既定値から変えた項目」の点と「デフォルトに戻す」は、使う人のプリセットでは、親のプリセットの値と比べ、親の値へ戻す

## 設定の画面

- 「表示」の先頭に、今使うプリセットの名前を値に出す「プリセット」の行を置き、プリセットを選ぶ画面を開く
- プリセットを選ぶ画面には、組み込みのプリセットと使う人のプリセットを並べ、今使うものにチェックマークを付ける。使う人のプリセットは、複製、名前の変更、削除ができる。組み込みのプリセットは、選ぶことと複製だけができる
- 「表示」から開いた「投稿の見た目」「通知の見た目」「メディア」で変えた値は、今使うプリセットに入る。組み込みのプリセットを使っているときに値を変えたら、それを親にした使う人のプリセットを作り、そちらに切り替える
- 設定のトップのアカウントの節に「表示」の行を置き、同じ3つの画面を、そのアカウントの上書きを変える画面として開く。どの層の値を変えるかは入り口で決め、画面の中に層を切り替える部品は置かない

## ショートカット

- プリセットを切り替えるアクションを、ショートカットに出す
