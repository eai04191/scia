# 投稿の見出しの並べ方

投稿の行で、アイコンの下を空けずに本文やメディアを広げることと、名前とハンドルを2段に分けることについて、作者が決めたこと。アイコンの下を空けないと、メディアを行の幅いっぱいに出せる。名前を2段にすると、名前の段とアイコンの高さが近くなり、アイコンの下から本文を始めても収まりがよい。

## 設定

- 「投稿の見た目」の「アイコン」に「アイコンの下を空けない」のスイッチを、「名前の行」に「名前とハンドルを2段に分ける」のスイッチを置く。どちらも既定はオフ
- 2つは別々の項目にし、どの組み合わせも選べる
- 「名前とハンドルを2段に分ける」は、「名前の表記」が名前とハンドルの両方を出すとき（「名前とハンドル」「ハンドルと名前」）だけ効く。片方だけを出すときは押せないようにする
- 2段のときだけ使う値として、「名前の行」に「1段目と2段目のあいだ」を足す

## 名前を2段に分ける

- 「名前の表記」の1つ目を1段目に、2つ目を2段目に置く。文字の大きさは、今の「太字の部分の文字」と「添える部分の文字」をそのまま使う
- 時刻、公開範囲の記号、編集済みの「*」は、1段目の右端に置く
- 2段目は、文字の列の幅をすべて使う
- 入りきらない名前の行末をぼかすのは、1段目と2段目のそれぞれで行う
- 1段目と2段目のあいだは、1段目の字面の下端から2段目の字面の上端までで測る
- 本文とのあいだ、本文がないときのメディアとのあいだは、2段目の字面の下端から測る

## アイコンの下を空けない

- アイコンと名前の段を見出しにする。見出しの下端は、アイコンの下端と名前の段の字面の下端のうち、下にあるほうにする
- 本文、注意書き、メディア、リンクカード、引用、投票、フィルターの注記は、見出しの下から、行の左右の余白の内側いっぱいに置く。「本文とのあいだ」と「本文がないときのメディアとのあいだ」は、見出しの下端から測る
- 名前の上の行（ブーストした人の行、返信と固定のラベル）は、今と同じく名前に揃える
- アイコンの位置と大きさ、名前の段の位置は、今と同じにする。アイコンの上端は名前の1段目の字面の上端に揃え、名前の段はアイコンの右に置く
- メディアの「本文の右に小さく」とも組み合わせられる。サムネイルは、行の右端に置き、上端を本文の1行目の字面の上端にそろえる。本文は、サムネイルとすき間の分をあけて、行の左端から折り返す
- 返信をつなぐ線は出さない。線はアイコンの下を通るが、そこに本文などが入るため。「返信をつなぐ線を出す」は、オンのあいだ押せないようにする
- 通知の一覧のメンションなどの投稿にも効かせる。お気に入り、ブースト、フォローなどの通知の行は、今のまま、アイコンの列の右に文字を置く。そのため通知の一覧では、行によって文字の左端が揃わない
- 引用やXの投稿の囲みの中の作者の行は、今のままにする

## 区切り線

- 投稿のあいだの区切り線は、行ごとに、その行の本文の左端から右端まで引く。アイコンの下を空けるときはアイコンの列に線を入れず、空けないときは行の左の余白から引く
- 通知の行（お気に入り、ブースト、フォローなど）、人の行、読み込みのすき間の行、読めなかった投稿の行は、アイコンの列の右の文字の列の左端から引く
