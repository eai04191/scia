# 投稿欄

投稿欄について、作者が決めたこと。

## ＋のメニューとボタンの行

- 公開範囲、添付、展開、注意書き、あとから増える投票や言語のような、投稿欄のボタンの項目も、長押しのメニューと同じ並びの設定で並べる。項目を足したときの差し込み方も同じ。どちらも[menus.md](menus.md)の「並びの設定」と「あとから項目が増えたとき」にある
- 「その他」の境目に当たる行を、＋のボタンに見立てる。境目より上の項目は＋のメニューに入れ、下の項目は投稿欄のボタンの行に常に出す。長押しのメニューとは上下が逆になるが、設定を上から読む順が、画面の左から並ぶ順（＋、行の項目）と同じになるようにするため
- ボタンの行に常に出す項目の数に上限は設けない。行に入りきらないときは、並びの後ろの項目から＋のメニューへ回す。端末の幅や文字の大きさで並びきる数が変わっても、行が崩れないようにするため
- ＋と項目のボタンは、幅を当たり判定の推奨の44ptに揃え、間を空けずに並べる。記号の幅で決めると、記号ごとに幅が違い、公開範囲を切り替えるだけで並びきる数が変わるため
- ボタンの行の記号と送信ボタンは、文字を大きくしても標準の最大で止め、残り文字数はその1段下で止める。アクセシビリティの大きさまで大きくすると、行に＋と1項目しか残らないため。止めた分は、タブバーと同じく、長押しで拡大して見せる。止めても、375pt幅の端末で＋を含めて5個は並ぶ。残り文字数と送信の間は詰めない
- 非表示にした項目は、ボタンの行にも＋にも出さない
- ボタンの行では、＋をいちばん左に置き、その後ろに項目を並びの順に置く
- この並びを変える画面を開く「カスタマイズ」も、ほかの項目と同じく並べる。行に出すことも、隠すこともできる
- ＋の中が空で、行に全部入るときは、＋を出さない
- ＋のメニューはボタンの上に開き、下ほど指が届きやすい。そのため、優先度の低い項目ほど上に置く。行に入りきらずに＋へ回した項目は、もともと行に出したかった優先度の高い項目なので、＋の中のいちばん下に入れる
- 閲覧注意は項目にせず、注意書きの項目で兼ねる。理由は[vision.md](vision.md)の「投稿欄」にある
- 既定の並びは、＋の中を上からカスタマイズ、区切り線、リンクにタイトルを付ける、注意書きにし、公開範囲、添付、展開をボタンの行に出す。ボタンの行は「＋ 公開範囲 添付 展開」になる

## リンクにタイトルを付ける

共有のときにURLしか渡さないアプリ（YouTubeなど）から貼ったリンクに、リンク先のページのタイトルを付ける。

- 自動では付けず、使う人が項目を押したときだけ付ける。本文が勝手に書き換わらないようにするため
- 項目を押すと、本文の中のURLを光らせ、光っているURLを押して選ばせる。リストから選ぶより、どのURLが変わるのかがその場で見えるため。URLが1つだけなら、光らせずにすぐ読み始める
- 光っている間に、光っていない場所を押す、打つ、項目をもう一度押す、書くのをやめるのどれかをしたら、光らせるのをやめる
- VoiceOverが動いているときは、光るURLを探して押すのが難しいため、項目をサブメニューにし、開いた時点の本文にあるURLを、本文に出てくる順に並べる。同じURLは1行にまとめる。URLが1つだけでも、どのURLに付くかが分かるようサブメニューにする
- 本文にURLがないときも、項目を消さずに押せない形で出す。押そうとしている間に、メニューの並びがずれないようにするため
- URLを選ぶと、リンク先のタイトルを読み、本文のそのURLの前にタイトルを入れる。URLが行の頭（本文の先頭か改行の直後で、前にその行の空白しかない）にあれば「タイトル、改行、URL」にする。共有で貼ったリンクのように、URLそのものが投稿の中身なので、タイトルを1行にして読みやすくするため。文の途中のURLは「タイトル、空白、URL」にし、行を増やさない。文として読めるようにするためと、欄が伸びて後ろの文が動かないようにするため。URLの直前が空白でない文字なら、タイトルの前にも空白を入れ、タイトルが前の文とつながらないようにする
- 同じURLが本文に2回以上あれば、押した1か所だけを置き換える。サブメニューから選んだときは、最初の1か所を置き換える
- 読んでいる間は、そのURLの上にきらめきを流す。読んでいることを、読んでいる対象の近くで見せるため。チップは出さない
- 読んでいる間も、打つのは止めない。読み終えたら、その時点の本文で同じURLを探し直し、押した場所にいちばん近いものを置き換える。URLが消されていれば何もしない
- 置き換えるときは、URLを置き換えたあとの位置へ動かし、空いた場所にタイトルを浮かび上がらせる。何が足されたのかを目で追えるようにするため。動きの途中で打つなどの操作をしたら、動きをすぐ終わりの形にして操作を受ける。視差効果を減らす設定では、動かさずに置き換える
- 置き換えは入力欄の取り消し（シェイクや⌘Z）で戻せるようにする
- タイトルは、リンク先のHTMLのog:titleを使い、なければ最初の`<title>`を使う。LinkPresentationには任せない。YouTubeでは動画の題ではなく投稿者の名前を返し、選び直す手段もないため
- タイトルの中の改行は空白にし、前後の空白は除く
- 読んでいる間は、「操作の状況」の進行中に並べる。読めなかったときと、タイトルのないページのときは、押し直せば済む失敗なので、アラートにせず数秒で消えるチップで知らせ、「操作の状況」の最近の失敗に残す。読めなかったときは、チップを押すと理由を出す
- 自分で貼ったリンクを読むだけなので、端末でリンクカードを作る機能と違い、オプトインにしない
