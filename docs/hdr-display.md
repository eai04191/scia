# HDRの表示

HDRの画像と動画を、どれくらいの明るさで描くか。作者が決めたこと。

## 設定

- 設定で、「ビューア以外」と「ビューア」のそれぞれに、「SDR」「控えめなHDR」「HDR」から選ぶ。一覧ではたくさんのメディアが文字と並び、ビューアではメディアだけを大きく見るので、ほしい明るさが違うため
- 「SDR」は、HDRのメディアもSDRの明るさに収めて描く
- 「控えめなHDR」は、HDRのまま、まわりのボタンや文字と並んでも眩しすぎないよう明るさを抑えて描く
- 「HDR」は、画面の明るさの上限まで使う。「写真」で見るより眩しくなる
- 既定は、ビューア以外が「SDR」、ビューアが「控えめなHDR」
- 選び直したら、開いている画面にもすぐ効かせる

## 対象

- 画像と動画のどちらにも効かせる。iPhoneで撮ったHDRの写真（ゲインマップ付き）と、HLGやPQのHDRの画像と動画が当てはまる
- ビューア以外は、タイムライン、通知、プロフィール、リンクカード、投稿欄のサムネイルなど、ビューアの外でメディアを描くところすべて
- Mastodonは、HDRの動画を作り直すときも、HLGのまま配信し、サムネイルもHLGの画像で作る。サーバーがSDRにしてくれることを前提にしない
- カスタム絵文字と、通知の一覧の行で文の先頭に並べるアイコンは、文字と一緒に描くので、設定にかかわらずSDRで出す。光らせるには1つずつビューを置く必要があり、一覧のスクロールが重くなるため
